### 📌 Projeto em destaque

**[Organizador de Tarefas com Prioridade Dinâmica](https://github.com/meloalexandev/Organizador-de-Tarefas-com-Prioridade)**

API REST em Java/Spring Boot para gerenciamento de tarefas com priorização dinâmica: a prioridade calculada automaticamente com base no prazo e no horário de consulta. Arquitetura em camadas (controller, service, repository, DTOs), validação de entrada com Bean Validation e persistência via Spring Data JPA.

`Java 17` `Spring Boot 3` `Spring Data JPA` `H2` `Lombok` `JUnit`
